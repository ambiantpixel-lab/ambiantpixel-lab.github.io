Install on macOS

  1. Download the pack from itch.io and unzip the Mac app.
  2. Move it to Applications and open it.
  3. The app is not notarized: the first time, open System Settings → Privacy & Security and click “Open Anyway”.
  4. The wallpaper now runs behind your icons and follows your clock.

Free option: the free Plash app can show any HTML file as a wallpaper. Point it to Jungle_16x9.html from the free download. Or open the file in Safari and go full screen.

FAQ

Does it drain my MacBook battery?

It renders at low resolution and 30 fps at most, which keeps it light, but any animated wallpaper uses some power. Quit the app on battery if you want every minute.

Why does macOS block it the first time?

The app is not notarized by Apple. Open System Settings → Privacy & Security and click “Open Anyway” once.

What about an external monitor?

The pack has 4K, 21:9 and 32:9 files for external displays. Plash can also show a different file on each screen.
