Set it up in Lively (2 minutes)

  1. Install Lively Wallpaper (free) from the Microsoft Store or its official site.
  2. Download Jungle Free from itch.io (enter $0 or any amount) and unzip it.
  3. In Lively, click + Add wallpaper and pick the file in Lively-Windows/, or Jungle_16x9.html.
  4. Click the new tile to set it. Lively pauses it while a game or full-screen app runs.
