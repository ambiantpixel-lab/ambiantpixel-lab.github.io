Add it to OBS in two minutes

  1. Unzip the pack.
  2. In OBS Studio or Streamlabs Desktop, add a Media Source, pick the MP4 or WebM and tick “Loop”, or add a Browser Source and point it to the HTML file.
  3. Set the source to 1920×1080. Done.
